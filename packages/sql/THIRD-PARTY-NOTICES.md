# Third party notices

This package's build includes the SQL grammars from
[node-sql-parser](https://github.com/taozhi8833998/node-sql-parser), by
Taozhi Wang and contributors, used under the Apache License 2.0.

The grammars are bundled rather than installed. The published package is
92MB of browser builds, source maps, and dialects this does not read,
and the four dialect builds used here come to about a megabyte once
bundled, so a project installing suss downloads that instead.

A copy of the Apache License 2.0 is in this package's LICENSE, which is
the same license suss itself ships under.
