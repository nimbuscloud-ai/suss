# subject-positions-python

One FastAPI route per file, each identical apart from where the app is
built. A pack recognizes a route by knowing which expression is the app,
and every language feature that moves a value is another place the app
can be written.

This is the Python half of a pair; `subject-positions` is the same
matrix in TypeScript. Before this fixture existed, two of these six were
found. The other four were lost, and each loss was a route that silently
did not exist.
