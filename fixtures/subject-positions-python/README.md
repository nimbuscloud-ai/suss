# subject-positions-python

One FastAPI route per file, each identical except for where the app is
built. A pack recognizes a route by knowing which expression is the app,
and every language feature that moves a value gives the app another
place it can be written.

This is the Python half of a pair. `subject-positions` is the same set
of cases in TypeScript. Before this fixture existed, suss found two of
these six routes. It lost the other four, and each one it lost was a
route that went missing without any warning.
